# Adarsh Pawar's portfolio site

This is a responsive, single-page portfolio ready for GitHub Pages.

## Make it yours

The site is personalised for Adarsh and includes three real mini-project demos:

- `projects/focus-desk.html` — a Pomodoro timer
- `projects/habit-tracker.html` — an interactive weekly tracker
- `projects/palette-maker.html` — a colour-palette generator

When you want to update it later, open `index.html` and replace:

- GitHub links with your profile link
- the short bio, location, and availability text

## Publish with GitHub Pages

1. Create a new GitHub repository named `portfolio`.
2. Upload all files in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show your website address after it publishes.

No build command is needed: open `index.html` in any browser to preview it locally.
